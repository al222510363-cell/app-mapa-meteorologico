# Mapa Meteorológico Global - Sistema de Consulta Meteorológica

Proyecto desarrollado para la asignatura IAW.

**Autor:** Gustavo

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- OpenStreetMap
- API Nominatim

## Descripción

Aplicación web que permite buscar ubicaciones geográficas y visualizar sus coordenadas, descripción y parámetros meteorológicos simulados.
